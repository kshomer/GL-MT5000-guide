# GL-MT5000 + MikroTik — домашняя сетевая инфраструктура: пошаговый гайд

Личный опыт настройки маршрутизатора GL.iNet GL-MT5000, DNS-резолвера, приватного
VPN-сервера для доступа к домашней сети, точки доступа Wi-Fi на MikroTik и базового
хардненинга VPS — оформленный в виде пошаговых, проверенных на практике инструкций.
Автор — не профессиональный сетевой инженер, а энтузиаст, изучающий эти технологии
на практике.

## Стек

- **Xray (VLESS + Reality + Vision)** — VPN-туннель;
- **AdGuard Home** — локальный DNS-резолвер, блокировка рекламы;
- **WireGuard** — удалённый доступ к домашней сети извне;
- **MikroTik** — точка доступа Wi-Fi за основным роутером.

## Особенности репозитория

- Собственный DNS: свой рекурсивный резолвер на VDS, не зависящий от сторонних
  DNS-провайдеров, и отдельно — локальный резолвер с блокировкой рекламы;
- Два независимых варианта удалённого доступа к домашней сети;
- Удобные скрипты для повседневного управления роутером: переключение между
  VLESS+Reality и VLESS+TLS и смена VPN-сервера по ссылке, смена версии ядра Xray
  с автоматической проверкой и откатом при сбое, точечные исключения роутинга по
  доменам, обновление geodata, управление WireGuard-клиентами вплоть до QR-кода
  для телефона — всё одной командой;
- Разделение трафика по geoip — часть через туннель, часть напрямую;
- MikroTik как отдельная точка доступа Wi-Fi и резервная «чистая» сеть без туннелирования.

## Структура репозитория

- `docs/` — пошаговые гайды;
- `scripts/` — скрипты с роутера, на которые ссылаются гайды.
