# xray-geoupdate — обновление geodata

Скрипт для обновления баз geodata (geoip.dat + geosite.dat) от Loyalsoldier.
Эти базы нужны для smart-ru роутинга (определение российских IP и доменов).

Расположение: `/opt/xray/xray-geoupdate.sh`, симлинк `/usr/bin/xray-geoupdate`.
В этом репозитории: `scripts/06-xray-geoupdate.sh`.

---

## Команды

```sh
xray-geoupdate         скачать свежие geoip.dat и geosite.dat, заменить, перезапустить
xray-geoupdate show    показать даты и размеры текущих файлов geodata
```

---

## Когда обновлять

geodata НЕ обновляется автоматически и НЕ связана с версией ядра Xray. Обновлять желательно
раз в несколько месяцев: со временем меняются российские диапазоны IP и списки доменов, и
старая geodata постепенно теряет точность (некоторые новые РФ-адреса могут пойти не туда).

Это не срочно — на работоспособность влияет медленно. Но раз в несколько месяцев освежить
полезно.

---

## Что делает (безопасность)

1. скачивает свежие geoip.dat и geosite.dat с GitHub (Loyalsoldier);
2. проверяет, что файлы скачались и не пустые (разумного размера);
3. бэкапит текущие в `/opt/xray/backup/`;
4. заменяет, проверяет конфиг через `xray -test`;
5. при успехе — перезапускает сервис; при ошибке — откатывает geodata.

---

## Пример

```sh
xray-geoupdate show      # посмотреть текущие даты
xray-geoupdate           # обновить
```

После обновления следует подождать ~30 секунд (перезапуск туннеля) и проверить доступ.

---

## Резервные копии

Скрипт хранит бэкап предыдущей geodata в:
`/opt/xray/backup/geoip.dat.backup` и `/opt/xray/backup/geosite.dat.backup`
